# Java-Course-Enrollment-Management-System
This project presents a console-based Course Enrollment Management System developed in Java. It addresses the need for managing student enrollments, course capacities, and academic eligibility based on GPA. The system allows administrators to add students and courses, enroll students with prerequisite and GPA checks, and view reports. It uses Object-Oriented programming (OOP) principles, file I/O for data persistence, and exception handling for robust input validation. The modular design ensures scalability and maintainability. Key modules include Student, Course, EnrollmentManager, and FileManager. This project demonstrates practical application of Java in building real-world academic systems.
